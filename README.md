# R8 Distribuidores

Página web con catálogo, hecha con React + Vite y publicada en GitHub Pages.

## Qué editar
- `src/data.js`: WhatsApp, correo, horario y **la lista de productos**.
- `src/styles.css`: colores (arriba, en `:root`) y diseño.
- `public/logo.jpg`: el logo.

## Probar en tu equipo
    npm install
    npm run dev

## Publicar
Cada `git push` a `main` publica la página solo (pestaña Actions en GitHub).
